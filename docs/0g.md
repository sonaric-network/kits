## Overview
0G is a blockchain ecosystem described as the first decentralized AI
operating system and the largest AI Layer 1 ecosystem. It operates on a
Proof-of-Stake (PoS) mechanism, enabling participants to run validator
nodes, validate transactions, propose new blocks, and earn rewards. The
platform emphasizes decentralization, scalability, and community
participation, with tools like Cosmovisor to streamline node operations
and upgrades. It is designed to be infinitely scalable for AI and
performant for everyone, enabling groundbreaking AI and Web3 applications.

## System Requirements
Hardware configuration required to set up an 0g node:

| Component     | Minimum | Recommended |
|---------------|---------|-------------|
| RAM           | 8GB     | 16GB        |
| CPU           | 8 core  | 8 core      |
| Storage (SSD) | 1 TB    | 4 TB        | 

## Getting Started

### Load Templates

```bash
cd 0g
sonaric load MANIFEST
```

```bash
foo@bar:~$ sonaric list 0g
```


### Configuration
Template variables can be set to customize the node's behavior. The following variables can be configured:

| Name       | Type   | Description                                                                                    | Default Value            |
|------------|--------|------------------------------------------------------------------------------------------------|--------------------------|
| `key_name` | string | The name of the key in the local keyring                                                       | `""`                     |
| `password`  | string | The passphrase for unlocking the key in the Keyring                                           | `""`                     |
| `staking_amount`     | string | The amount of tokens for self-delegation or other operations                         | `"1"`                    |
| `validator_name` | string | The moniker (display name) of the validator, shown in explorers and validator listings.  | `""`                     |
| `validator_description` | string | A brief description of the validator that users see in the list of validators.    | `""`                     |
| `keybase_id` | string | Links the validator to a verified identity on Keybase                                        | `""`                     |
| `chain_id` | string | The network identifier. By default for 0g, it's `zgtendermint_16600-2`                         | `"zgtendermint_16600-2"` |

### Run 0g node

To run the 0g node, execute the following command:

```bash
sonaric run 0g/validator-node
```

## 0g Template Actions

### Start validator node

To start the validator node, execute the following command:

```bash
sonaric do 0g/validator-node/start-validator
```
